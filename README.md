# Secure-Programing-CW2---SecuredNotes

  - UI `https://localhost:5173` (TLS), Postgres `localhost:5432`
- `secure-notes-frontend` / `secure-notes-backend` / `secure-notes-database` — source for the secure app
- `insecure-notes` — Insecure app via Docker Compose
  - UI `http://localhost:5174`, API `http://localhost:3001`, Postgres `localhost:5433`
